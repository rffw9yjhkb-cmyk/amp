Manual — 操作方法

Tesla Model 3（ハイランド）の基本操作をまとめました。このモデルはシフトレバーとウインカーレバーがありません。最初にここだけ押さえれば、あとは普通の車と同じ感覚で運転できます。

解錠・施錠Unlock / Lock

  • スマホキーで登録済みのスマホを持って近づくと、そのままドアを開けられます。
  • ドアハンドルは、太い部分を押すと細い部分が起き上がるので、そこを引いて開けます。
  • 施錠は自動です。車から離れるとロックされます（施錠し忘れの心配はありません）。
  • スマホの電池が切れたときは、カードキーを運転席側の柱（Bピラー）にかざしてください。

運転のはじめ方Start Driving

  • ブレーキを踏むと画面が点灯し、出発できる状態になります。
  • シフトは画面で操作します。画面左端の車のアイコンを上にスワイプでD（前進）、下にスワイプでR（後退）です。
  • 画面が使えないときは、ルームミラー上の天井コンソールのボタン（P / R / N / D）でも操作できます。

オートパイロット（オートステア）の使い方とコツAutopilot / Autosteer

  • 使い方は、走行中にハンドル右側のスクロールボタンを押すだけです。車線の中央維持と、前走車に合わせた加減速を車が手伝います。解除はブレーキを踏むか、もう一度ボタンを押します。
  • 絶対に前を見続けてください。車内カメラがドライバーの視線を見ています。スマホや画面へのよそ見が続くと警告が出ます。
  • ハンドルには常に軽く手を添え、一定の負荷（トルク）をかけ続けてください。ただ触れているだけでは検知されず、警告が出ることがあります。
  • 警告を無視すると、その場でオートステアが強制解除されます。この強制解除が複数回たまると、約1週間オートパイロットが使えなくなる場合があります。警告が出たら、すぐ前方を見てハンドルに負荷をかけ直してください。
  • あくまで運転支援です。いつでもご自身でハンドル・ブレーキを操作できる状態でご利用ください。

ウインカー・ワイパーTurn Signals / Wipers

  • ウインカーはハンドル左側の矢印ボタンです。レバーはありません。
  • ワイパーはハンドル右側のボタンです。押すと1回作動、長押しでウォッシャー液が出ます。速さは画面に出るメニューで変えられます。
  • ハザードは天井コンソールの三角マークのボタンです。

停め方Parking

  • 停車したら、シートベルトを外すだけで自動でP（パーキング）に入ります。わざわざPボタンを押す必要はありません（画面の「P」ボタンでも入れられます）。
  • あとは降りて離れるだけで、自動でロックされます。
  • 車内からドアを開けるときは、ドア上部のボタンを押します。

充電のしかたCharging

  • 充電ポートは車両の左後ろです。カバーを軽く押すか、画面の充電アイコンから開きます。
  • スーパーチャージャーは、ケーブルを差すだけで充電が始まります。終わったらケーブルのボタンを押しながら抜き、元のホルダーに戻してください。
  • 充電が完了したら、速やかに車両の移動をお願いします。完了後5分を過ぎてもそのまま停めていると、Teslaの定めるアイドル料金（放置料金）が発生します。ステーションが半分以上埋まっているときは1分50円、満車のときは1分100円です。発生した場合は、実費でご精算いただきます。
  • ご返却時は、充電75%程度を目安にお願いします（充電代は料金に含まれています）。

トランク・収納Trunk / Storage

  • 後ろのトランクは、画面または車両後方のボタンで開きます。
  • 前のトランク（フランク）とグローブボックスは、画面の「コントロール」から開けます。

困ったときHelp

操作で分からないことがあれば、無理に操作せず、お問い合わせからオーナーへご連絡ください。事故・故障などのトラブル時はトラブルの場合のページをご覧ください。
